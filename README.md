# WRATH — Companion

An out-of-universe companion to **WRATH**: the world, the Powers, the fallen, the language and
register, the published work, and what is still unsettled.

**Read it → https://schmede-ai.github.io/wrath-companion/**

It is written for someone who has offered to help write in this universe and needs to get up to
speed. It explains the fiction. It is not written in the voice of the fiction, and it carries no
production or pipeline material.

**It is derived, not authoritative.** The working canon is the authority; this is curated out of it
for a reader. Where the two disagree, canon is right.
